# Etapa 8: Layout Base e Navegacao

## Objetivo

Organizar a area interna com um layout mais profissional, navegacao clara e estrutura pronta para receber as telas do sistema.

## O que foi feito

- sidebar com navegacao principal
- cabecalho interno com acao de logout
- dashboard reorganizado
- rotas base para `students`, `students/new` e `reports`

## Rotas internas criadas

- `/dashboard`
- `/students`
- `/students/new`
- `/reports`

## Como validar

1. Rode `npm run dev`
2. Entre no sistema
3. Teste o menu lateral
4. Abra cada rota interna
5. Confirme se o layout permanece consistente entre as paginas
