# Etapa 11: Busca, Filtros e Exportacao

## Objetivo

Deixar o modulo de alunos mais pratico para o uso diario com busca, filtros e exportacao em CSV.

## O que foi feito

- busca por nome, email ou celular
- filtro por turma
- filtro por professor
- exportacao CSV respeitando os filtros atuais
- resumo visual dos filtros ativos

## Como testar

1. Abra `/students`
2. Digite um nome no campo de busca e filtre
3. Teste os filtros de turma e professor
4. Clique em `Exportar CSV`
5. Confirme se o arquivo baixado segue a listagem filtrada
